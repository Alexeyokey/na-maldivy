## Исправленные ошибки

| Область | Ошибка | Поведение после исправления |
|---|---|---|
| Оформление | После обновления страницы оплаченный заказ оставался только в списке поездок; текущая поездка снова предлагала оформление | Заказ восстанавливается по защищённому GET и показывается как оплаченный; документы доступны |
| Потерянный ответ оплаты | Сервер уже создал заказ, а клиент не получил ответ | GET состояния восстанавливает исходный заказ, повторная оплата не требуется |
| Проверка результата оплаты | Неверная сессия/корзина или неполный ответ могли считаться успехом и сбрасывать ключ повтора | Заказ проверяется до применения, ключ идемпотентности сохраняется при неоднозначном результате |
| Обновление состояния | Неуспешный GET корзины мог оставить клиент с наполовину обновлённым состоянием | Снимок применяется после успешных проверок связанных объектов; запоздалые ответы не меняют новую поездку |
| Версии диалога | Некорректный `done` мог сменить сессию или откатить версию | Клиент сохраняет возможность восстановления и отвергает несогласованные данные |
| Локальный UI-прототип | Нулевой/нечисловой общий бюджет отключал фильтр, остаток бюджета и ранний заезд считались несогласованно | Неверный бюджет не даёт выдачу, стоимость всей поездки и разовая доплата используют общий расчёт |
| S5: длительность | Короткий трансфер туда скрывал нарушение ограничения у обратного трансфера | Проверяется каждое плечо |
| S5: рекомендации | Исправление проблемы с детским креслом могло предложить транспорт, запрещающий питомца семьи | Альтернатива проверяется также на другие известные критические ограничения |
| S5: обратный рейс | Рекомендуемый обратный трансфер мог не успевать в аэропорт или нарушать предел длительности | Такие альтернативы не предлагаются |
| S5: цена | Известная нулевая стоимость дополнительной ночи превращалась в неизвестную | Сохраняется нулевая расчётная цена |
| S4: загрузка | Дубли пары отель/аэропорт или ID варианта молча перезаписывали данные; цена за машину без вместимости падала при поиске | Ошибка обнаруживается при загрузке каталога |
| D4: контроль снимка | Проверка пропускала неполный/повторённый список файлов и неверные метаданные manifest | Проверяется полное соответствие файлов, маршрута, даты записи и SHA256 тела |
| Модель: ошибки | Сырой ответ провайдера, невалидные аргументы или HTTP 200 с повреждёнными полями могли попадать в исключения, журнал и предупреждения | Ошибки нормализуются без исходных значений и цепочек диагностик |
| Codex: память | Размер stdout/stderr проверялся после полного чтения процесса | Предел применяется во время чтения; превышение прекращает процесс и его дочерние процессы |
| Исходный ZIP | Репетиция данных зависела от наличия `.git` после успешного выполнения | В архиве сохраняются хеши исходников, commit обозначается `null` |

Для подтверждённых багов добавлены регрессионные сценарии. Проверка размера
вывода Codex использует настоящий локальный дочерний процесс без аккаунта и
сети: процесс пишет избыточный поток и зависает; адаптер должен остановить его
раньше общего таймаута, удалить временную папку и не засчитать успешный вызов.
Предел — 4 МиБ отдельно для stdout и stderr. Содержимое диагностики в журнал
приложения не перепечатывается.

## Самодостаточность данных

[Подробный инвентарь](data-inventory.md) содержит происхождение и ограничения
всех наборов. В Git есть 247 файлов `data/`, в том числе 60 отелей, 136 вариантов
трансферов, 1440 синтетических отзывов, 60 профилей и 47 очищенных ответов
Aviasales. Некоторые результаты для дат/состава группы создаются кодом,
поэтому отдельная запись каждого возможного ответа не нужна.

Новый архив только из отслеживаемых файлов проверен с пустым HOME, очищенным
окружением и запретом socket/DNS. Пройдены проверки данных, CLI и трёх
направлений до демо-оплаты/документов. Пять генераторов воспроизвели байты
каталогов. Секреты, личные чаты, runtime-базы, веса моделей и Docker-образы
в Git не входят и не требуются для офлайн-демо.

## Границы проверки

Зелёные тесты и перечисленные исправления не доказывают отсутствие любых
ошибок. Коммерческие условия и наличие мест остаются демонстрационными;
настоящий Яндекс и настоящее LLM-извлечение D7 не проверялись. Офлайн-модель
`fake` проверяет работу кода, но не качество свободного диалога Luna.

Исходный O2-сценарий u2-03 с бюджетом 150 000 ₽ требует вариантов при минимуме
известных расходов 153 378 ₽. Этот конфликт исходного критерия не исправляется
выдуманной ценой или отключением бюджетного фильтра. Условия и исходные отчёты
сохранены в [готовности к сдаче](submission-readiness.md).
