# Приёмка общего интерфейса без внешней модели

Это исторический протокол прежнего среза. [Новая репетиция и открытые проверки](judge-ui-rehearsal.md)
относятся к `de83c11`; старые суммы и наблюдения ниже не являются новым прогоном.

Интерфейс из main `3ba5dbc` связывается с настоящим сервером. Локальный
`CHAT_MODE=demo` остаётся отдельным прототипом и не считается API-прогоном D9.

## Проверяемый путь

1. Открыть новую поездку в API-режиме, проверить доступность сервера.
2. Ввести: «Из Москвы в Анталью 18 ноября 2026 на неделю вдвоём».
3. Увидеть карточки из серверного `options`: исходные котировки 11 251/14 147 ₽
   за место, известные компоненты первого варианта 83 234 ₽. Неоценённые доплаты
   видны, неизвестные значения не заменены нулём.
4. Попросить объяснение отеля: число и буквальная цитата, пометка синтетических отзывов.
5. Сравнить даты: 16 ноября, 71 086 ₽, экономия 12 148 ₽. Выбор ещё не меняется.
6. Выбрать безопасный первый вариант и явно подтвердить оформление. Сервер создаёт
   корзину, она ещё не оплачена.
7. Ввести только вымышленные имя/дату рождения для двух взрослых. Подтвердить,
   что это демо и что часть расходов не оценена. Номера карт/CVV не нужны.
8. Проверить тестовый отказ, затем успешный повтор. Успех берётся из `paid_demo`
   сервера, а не локального флага интерфейса.
9. Скачать HTML-ваучер и `.ics` через серверный API. На ваучере есть отметка демо
   и источники каждого плеча. Идентификатор доступа передаётся заголовком, не URL.

Дубай отдельно: туда явный мок DXB, обратно настоящая запись, сумма известных
компонентов 131 161 ₽. Мальдивы: оба плеча из настоящих записей, 216 983 ₽,
безопасный совместимый трансфер. При моках не называть экономию настоящим тарифом.

## Протокол D9

Пять последовательных автоматизированных проходов через отображаемый UI выполнены
на версии `a728e37`: 9,247; 7,216; 7,787; 6,574; 6,727 секунды. Каждый до 300 секунд.
Доказательства — [`eval/demo-runs.json`](../eval/demo-runs.json). Это время
автоматизации элементов интерфейса, не измерение скорости человека.

Проверены уведомления об успешном скачивании после серверного GET. Содержимое
ваучеров и календарей отдельно проверено через тот же прокси:
[`three-destination-ui-proxy-2026-10-28.json`](../eval/reports/three-destination-ui-proxy-2026-10-28.json).
Пробный проход с затянувшимся ожиданием пути загруженного файла исключён из
зачётной серии и сохранён как неуспешный `warmup-slow-download.json`.

Для следующих проверок:
Для каждого сохранять начало/конец, длительность, шаги и наблюдаемый результат,
метод (`computer_use_ui_automation` либо `human`), версию кода и доказательства.
Серверные тесты не подставляются вместо браузерных. Автоматизированный UI-прогон
не называется человеческой репетицией выступления.

`eval/demo-runs.json` заполняется только после фактического выполнения; `trace`
указывает на публичный JSON внутри `eval/reports`, scope
`integrated_product_through_demo_payment_and_voucher`, `integrated_ui_status=performed`.
В публичные доказательства не включать реальные персональные данные, accessID,
ключи и приватные заголовки. Фактическое успешное оформление не означает покупку.

После автоматизированных проходов нужны две репетиции выступления с таймером и резервное видео
до 5 минут. До записи видео не добавлять выдуманную ссылку в README.
