# Карта документации

Для проверки решения начните с [README проекта](../README.md) и
[маршрута судьи на 5–10 минут](judge-guide.md). Достаточно Docker/Compose
и браузера; инструкции владельца сервера для этого не нужны.

Стандартный `FLIGHTS_MODE=demo` поддерживает полный демонстрационный контур
48 направлений: 60 исходных OSM-отелей плюс 360 вымышленных, с перелётами,
трансферами, синтетическими отзывами и демо-оформлением. Строгие режимы
`synthetic`/`aviasales` сохраняют исходные три направления. Источники и
ограничения отделены в [карте данных](../data/README.md) и
[инвентаре](data-inventory.md); новое покрытие не подтверждает реальное наличие.

## Отдельные установки и история

`vps-deployment.md`, `personal-codex.md` и `private-server-codex.md` описывают
дополнительные установки владельца. Они не входят в обязательный локальный
запуск, не предоставляют доступ к личному аккаунту и не заменяют демо без ключей.

[Ранний план сдачи](submission-readiness.md),
[аудит 28 октября](code-audit-2026-10-28.md) и отчёты в
[`eval/reports/`](../eval/reports/) сохранены как история. Сверяйте дату,
проверенный commit и область проверки в каждом отчёте. Старые количества
тестов, порты и утверждения о состоянии веток не описывают новую сборку.
