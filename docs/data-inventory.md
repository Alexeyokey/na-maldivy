## Важна ветка

В проверенном `origin/main` (`63b4c2f`) есть только 6 файлов данных S4:
`data/hotels/osm_hotels.json` и 5 файлов `data/transfers/`.
Обычный `git clone` с переходом на эту версию `main` **не получает весь набор D2–D8**.

Полные `data/` в `origin/codex/private-demo-access` (`37037e6`) и
`origin/codex/submission-readiness` (`6752b8d`) побайтово совпадают.
Первая ветка также содержит закрытый интерфейс Codex и восстановление чата;
для офлайн-данных эта интеграция не требуется.

```bash
git clone --branch codex/private-demo-access --single-branch https://github.com/ostrovok-hackathon-2026/na-maldivy.git
cd na-maldivy
uv sync --project backend --locked
make demo-cache-check
uv run --project backend --locked --offline python scripts/build_hotel_profiles.py --check
make three-destination-rehearse
```

Первой установке Python-зависимостей нужен доступ к пакетам либо подготовленный
кэш `uv`. Сами проверки и данные работают без сети. Для интерфейса используется
`make demo-up`; первой сборке Docker нужны базовые образы и пакеты либо заранее
подготовленный офлайн-пакет. Архив Docker-образов не хранится в Git.

Данные не подтверждают наличие мест, цену покупки или условия реального отеля.
Лицензии и ограничения перечислены в `data/ATTRIBUTION.md`,
`data/CBR-ATTRIBUTION.md` и README соответствующих каталогов.

`TOOLS_MODE=stub` выбирает отдельный минимальный набор D1. Для общего каталога

`CACHE_MODE=replay`. Код stub также отслеживается Git, его сведения не следует
смешивать с источниками общего каталога.

## Генераторы

Все следующие команды используют сохранённые входы, работают без сети и
воспроизвели опубликованные файлы побайтово:

```bash
uv run --project backend --locked --offline python scripts/fetch_hotels.py
uv run --project backend --locked --offline python scripts/build_hotel_rules.py
uv run --project backend --locked --offline python scripts/build_hotel_profiles.py --generate-reviews
uv run --project backend --locked --offline python scripts/build_destinations.py
uv run --project backend --locked --offline python backend/scripts/build_transfers.py build
```

`fetch_hotels.py` вопреки историческому имени делает локальную проекцию общего
каталога. Настоящее обновление OSM/OSRM — отдельная сетевая команда
`backend/scripts/build_transfers.py fetch`; обновление климатических снимков —
`scripts/fetch_destination_climate.py`. Для воспроизведения демо они не нужны.
Синтетические JSON-формы Aviasales/Яндекса написаны вручную, их не следует
перезаписывать или выдавать за записанные ответы провайдера.

## Что намеренно отсутствует

- Ключи Aviasales/Яндекса/OpenAI, `.env`, пароли сайта, SSH-данные, авторизация Codex и TLS-ключи.
- Частные runtime-кэши `data/cache/aviasales/`, `data/cache/yandex/`, `.runtime/` и `artifacts/`.
- История личных чатов, реальные заказы, runtime SQLite и браузерные данные.
- Настоящий записанный ответ Яндекс Расписаний: в репозитории есть только синтетическая фикстура.
- Результаты настоящего LLM-извлечения D7: 60 опубликованных профилей получены воспроизводимым лексическим baseline, не LLM.
- Веса локальной модели, загруженные зависимости и собранные Docker-образы.

Публичные очищенные Aviasales-снимки специально перенесены в
`data/demo/aviasales/`, поэтому отсутствие частного runtime-кэша не мешает демо.

## Результат независимого воспроизведения

Из `git archive 37037e6` извлечены только отслеживаемые файлы. Создано новое
окружение из lock-файла в offline-режиме с подготовленным кэшем пакетов.
Пустой HOME и очищенное окружение исключили доступ к ключам; подключения
socket и DNS были запрещены на уровне Python.

Прошли 10 проверок: D5, проекция D3, правила D3, D7, 47 Aviasales-снимков,
CLI D2/D4/D6/D8 и HTTP-сценарий всех трёх направлений до демо-оплаты,
ваучера и календаря. Все 5 генераторов воспроизвели исходные байты `data/`.
Настоящий LLM и внешний API при этом не вызывались; браузерный UI в этой
проверке не запускался.

С исправлениями аудита в том же изолированном окружении прошли **548 тестов**
данных и инструментов, включая загрузку повреждённой базы S4, целостность
manifest Aviasales и пять прогонов из исходного архива без Git.

`eval/reports/data-bundle-audit-2026-10-28.json`.
