# Подготовка резервного видео S8

Общий UI уже подключён к серверному API. Видео для сдачи пока не приложено;
ниже сценарий записи проверенной сборки. Стандартный адрес — localhost:8080,
запуск описан в [README](../README.md). HTTP-трассы и скриншоты не заменяют
запись пользовательского интерфейса и общедоступную ссылку на неё.

| Время | Действие и проверяемое содержание |
|---|---|
| 0:00–0:25 | Название, команда, «демонстрация без внешней модели». Сказать, что оплата тестовая. |
| 0:25–1:15 | Анталья 18 ноября 2026, двое на неделю. Показать варианты, группу, источники обеих котировок и неоценённые доплаты. |
| 1:15–1:50 | Спросить, почему подходит отель. Показать буквальную цитату и отметку синтетических отзывов. |
| 1:50–2:30 | Сравнить соседние даты: 83 234 против 71 086 ₽, разница 12 148 ₽. Исходный выбор не изменяется. |
| 2:30–3:15 | Выбрать безопасный вариант, подтвердить оформление. Корзина ещё не оплачена. Ввести вымышленные данные. |
| 3:15–4:10 | Явно подтвердить демонстрационную оплату и неполную стоимость. Показать отказ и повторный успешный тест. |
| 4:10–4:40 | Открыть демо-ваучер и календарь, показать отметку «билеты не выписаны». |
| 4:40–4:55 | Кратко: реальные авиакотировки из кэша, расчётные остальные компоненты, общий интерфейс/модель только в фактически проверенном состоянии. |

При записи Дубая показать отметку мок-рейса туда. Не называть его котировкой
Aviasales. Для проверки ловушек Мальдив используйте отдельный сценарий и не
подтверждайте вариант с критической проблемой.

Перед записью: скрыть приватный `.env`, ключи, заголовки доступа, терминалы
с секретами и реальные персональные данные. Использовать только вымышленных
путешественников. Поднять проверенную сборку заранее, проверить звук и таймер.

Приёмка S8: реальная запись полного пути до 5 минут, ссылка открывается без
входа и добавлена в README. Загрузку и отправку видео выполнять после выбора
командой площадки. Сейчас публичной ссылки на готовое видео нет.
