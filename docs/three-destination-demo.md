## Почему у Дубая мок

API на 15–21 ноября возвращает DWC вместо DXB. Мы не переименовываем аэропорт,
не используем такую котировку для трансфера из DXB и не приписываем цену Aviasales.
Отдельный демо-режим генерирует синтетический рейс с `demo_source.kind=deterministic_mock`.
Возврат 25/26 ноября опирается на подходящую настоящую запись DXB → SVO.

На Мальдивах ночной прилёт не принуждает выбирать небезопасный гидросамолёт:
для JEN найден совместимый трансфер на такси. Таймлайн и валидатор работают
с местным временем. Критические варианты не допускаются к демо-оплате.

## Граница режима

- `aviasales`: строгий provider/replay без подмены источника.
- `synthetic`: полностью демонстрационные рейсы.
- `demo`: только replay, затем подписанный мок при CacheMiss/корректном отсутствии
  подходящей котировки. Ключ игнорируется, сеть не открывается.
- Слишком дорогая существующая котировка, повреждённый кэш или ошибка провайдера
  не заменяются более дешёвым мок-рейсом.
- `demo_source` передаётся для каждого плеча в карточку, текст и ваучер.
  `price_source` Aviasales бывает только у настоящей записи.
- D8 при любом участии мока ставит `savings_kind=demonstration_estimate`.
  Арифметика и сопоставимость всё равно проверяются, но это не доказательство
  настоящей рыночной экономии.

## Повторить проверку

```sh
make demo-up
make three-destination-rehearse
make submission-eval
```

Три полных backend-прогона включают поиск, D7, D8, выбор, неоплаченную корзину,
вымышленных путешественников, тестовый отказ/успех/повтор оплаты, ваучер, `.ics`
и восстановление того же заказа после перезапуска приложения. Полный отчёт:
[three-destination-backend-2026-10-28/report.json](../eval/reports/three-destination-backend-2026-10-28/report.json).
В отчёте сохраняются источники по плечам и сопоставление с телами D4; личные
идентификаторы доступа не публикуются. Эти прогоны проверяют HTTP backend,
а не готовность общего UI или выполнение человеческого D9.

Поезда для сдачи — явные моки `TRAINS_MODE=synthetic`, ключ Яндекса не нужен.
Настоящий доступ к Яндексу и внешняя модель остаются отдельными этапами.
