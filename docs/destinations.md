# D5: справочник направлений

Справочник и подбор работают локально без сети, ключей и LLM. Доменный API D5
подключён к реестру инструментов и `/api/chat`.

В стандартном запуске (`TOOLS_MODE=real`, `FLIGHTS_MODE=demo`) полный
демонстрационный подбор подключён ко всем **48 направлениям D5**: перелёты,
отель, трансфер, профиль синтетических отзывов, сравнение дат и демо-оформление.
Это охват кода и подготовленных данных; жёсткие ограничения пользователя могут
дать пустую выдачу. Перелёт LED → LED не создаётся.

В чате карточки различают **«Подобрать поездку»** и **«О направлении»** по
фактически подключённым источникам текущего режима. Поле
`full_trip_supported` описывает охват демо-подбора, а не подтверждённое наличие.
Кнопка передаёт стабильный IATA-код, поэтому склонение или язык названия не
меняют выбранный аэропорт. Имена и алиасы из D5 распознаются также в явных
текстовых запросах; неоднозначное название не выбирается автоматически.

Например, **«Из Москвы на Шри-Ланку в январе 2027, двое взрослых, 7 ночей»**
в режиме `demo` запускает подбор CMB с явно помеченными мок-рейсами и
вымышленными демо-отелями. У Петербурга кнопка отправляет
**«Хочу в LED, самолётом»**, чтобы поездка не превратилась в поиск поездов.
Команда **«Расскажи о направлении CMB»** предназначена для сохранённой справки,
а не подтверждения цены или наличия. Для отдельного справочного сценария
начните новую поездку.

Строгие режимы `FLIGHTS_MODE=synthetic` и `FLIGHTS_MODE=aviasales` не включают
новые гостиничные и транспортные дополнения: полный исходный контур остаётся
AYT/DXB/MLE, а остальные записи доступны как справочные. Режим `aviasales`
не подменяет отсутствующие котировки моками. Прежние оплаченные демо-заказы
и документы сохраняются при смене направления.

## Что входит

- 48 направлений и их аэропорты-ориентиры, русские/английские названия и aliases.
- Месячные климатические нормы 1991–2020: воздух, осадки, морская поверхность для 27 пляжных направлений.
- Расчётные оценки времени полёта из Москвы и Петербурга с явно указанным методом.
- Визовые сведения для обычного паспорта РФ, туризм: проверенные правила отделены от неизвестных.
- Строгие фильтры и объяснимый скоринг; результат содержит причины включения и исключения.

Цены пока `null` и `pending`: их источники — D2 и D3. D5 не подменяет неизвестные цены выдуманными
суммами. Если задан жёсткий бюджет, неизвестная цена исключает вариант с причиной `unknown_price`.
Синтетические цены расширенного демо рассчитывают D2/D3/S4 отдельно от D5:
они не превращают неизвестную справочную цену в проверенную котировку.
Сохранённые визовые сведения не заменяют проверку условий въезда.

## Данные полного демонстрационного подбора

Исходные 60 OSM-отелей AYT/DXB/MLE, 6 маршрутных записей и 47 очищенных
снимков Aviasales сохранены. Для остальных 45 направлений, включая LED,
добавлены 360 **вымышленных** отелей — по 8 на цель, с идентификаторами
`demo:hotel/CMB-01` и аналогичными. Их имена, координаты, коммерческие условия
и отзывы сгенерированы; они не приписываются реальным отелям или OSM.
Координаты — детерминированные смещения от аэропортов-ориентиров D5.

Всего в opt-in демо: **420 отелей, 10 080 синтетических отзывов, 420 профилей,
95 маршрутных записей (6 исходных + 89 новых) и 420 записей трансферов**.
У нового направления есть семейные, pet-friendly, возвратные и круглосуточные
синтетические варианты, а также adults-only и ограниченные тарифы.
Наличие у поставщиков, реальная прямота рейса и дорожный маршрут не проверены.
Обратный трансфер, визы и прочие обязательные доплаты не оценены.

Пути, происхождение и воспроизведение: [инвентарь данных](data-inventory.md)
и [атрибуция](../data/ATTRIBUTION.md). Пошаговая проверка CMB —
в [руководстве судьи](judge-guide.md#3-дополнительные-проверки).

## Запуск

```bash
cd backend
uv sync  # один раз подготовить окружение с зависимостями и pytest
cd ..
make destinations
make destinations DESTINATIONS_ARGS="--month 11 --visa-free --json"
```

`make destinations`, `make destinations-data` и `make destinations-check` используют готовое
окружение `backend` с `uv run --offline --no-sync`. При отсутствии зависимостей они завершаются
ошибкой; установку или обновление окружения выполняйте отдельно.

Другие примеры из `backend`:

```bash
uv run python -m app.destination_cli --month 11 --tag beach --min-water 24
uv run python -m app.destination_cli --month 11 --tag beach --min-water 24 --visa-free
uv run python -m app.destination_cli --month 1 --tag mountains --origin LED --max-flight-minutes 300
uv run python -m app.destination_cli --resolve 'Бишкек'
uv run python -m app.destination_cli --month 11 --tag beach --min-water 24 --json
uv run python -m app.destination_cli --month 11 --departure-date 2027-11-15 --visa-free --json
```

При заданном бюджете до появления цен результат будет пустым с явной диагностикой:

```bash
uv run python -m app.destination_cli --month 11 --budget 150000 --travelers 2
```

В Python:

```python
from app.tools.destinations import resolve_iata, suggest_destinations

result = suggest_destinations(
    month=11,
    preferences={"tags": ["beach"], "min_water_temp_c": 24},
    origin="MOW",
)
for item in result.candidates:
    print(item.destination.name, item.climate.water_temp_c, item.score, item.reasons)

print(resolve_iata("Анталья"))  # ('AYT',)
```

`resolve_iata` возвращает все совпавшие аэропорты-ориентиры. При неоднозначности нельзя молча
выбирать первый результат. Это конечный справочник направлений, а не полная база городов мира.
IATA Бишкек — `BSZ` с 9 августа 2025 года; старый `FRU` сохранён как alias,
изменение подтверждено [оператором аэропорта](https://airport.kg/ru/news/15).

## Источники и точность

| Данные | Источник | Как обработано |
|---|---|---|
| Аэропорты, координаты, IANA timezone | [mwgg/Airports](https://github.com/mwgg/Airports), MIT | Закреплены commit и SHA256; 48 записей и две точки отправления |
| Воздух и осадки | [NASA POWER / MERRA-2](https://power.larc.nasa.gov/docs/services/api/temporal/climatology/), CC BY 4.0 | `T2M`, `PRECTOTCORR`, базовый период 1991–2020 проверяется в каждом ответе |
| Температура морской поверхности | [NOAA OISST v2.1, NOAA PSL](https://psl.noaa.gov/data/gridded/data.noaa.oisst.v2.highres.html) | Климатология 1991–2020, сетка 0.25°, ближайшая полноценная морская ячейка |
| Визовые правила | МИД и посольства соответствующих стран | Ручная проверка с датой и ссылкой, только применимый обычный паспорт РФ |
| Теги | Авторская классификация D5 | Удобство навигации; `family` не гарантирует конкретную услугу отеля |

Данные воздуха относятся к ячейке MERRA-2 у аэропорта. В горной/прибрежной местности её средняя
температура может заметно отличаться от конкретного курорта. NOAA описывает морскую ячейку,
а не температуру отдельного пляжа. Все значения — климатические нормы, **не прогноз** на даты поездки.

Для воды отбиралась ближайшая ячейка в радиусе до 100 км с полными 12 месяцами и минимум 27 годами
данных. В текущем срезе все 27 ячеек имеют 30 лет, максимальная дистанция — около 30.6 км.
Координаты ячейки и расстояние сохранены в `data/sources/climate.json` и пояснениях направления.
Для остальных 21 направления морская температура `null`: неизвестное не заменяется нулём.

Осадки NASA приходят в **мм/день**. Пересчёт в мм/месяц использует среднюю длину соответствующего
месяца за 1991–2020, включая високосные годы. Отдельно сохранены исходные ответы с URL запроса.

Acknowledgements: meteorological data provided by NASA POWER (MERRA-2), licensed CC BY 4.0
according to the [provider dataset registry](https://registry.opendata.aws/nasa-power/).
Sea surface temperature data provided by NOAA PSL, Boulder, Colorado, USA, from
[psl.noaa.gov](https://psl.noaa.gov). The MIT copyright and permission notice for mwgg/Airports
is preserved in `data/sources/airports-MIT-LICENSE.txt`.

## Оценки перелёта

Формула: расстояние по большой окружности от аэропорта-ориентира / 750 км/ч + 45 минут,
округление вверх до пяти минут. Москва привязана к SVO; Петербург — к LED.

**Это географический ориентир.** Наличие прямого рейса, ограничения воздушного пространства,
реальный маршрут, пересадки и время ожидания не проверяются. Расписание и фактическую длительность
должен предоставить D2. Пункт отправления не предлагается как направление для авиаперелёта.

## Визы и неизвестные сведения

Дата среза — 26 октября 2026 года. Для всех 21 зарубежной страны теперь сохранены правила
визового режима со ссылками на официальные источники и оговорками. Это проверка самого режима,
а не всех условий допуска. Численные сроки, которые не удалось установить однозначно, остаются
`null`; это не разрешение на неограниченное пребывание. Россия — внутренняя поездка гражданина РФ.

Для Мальдив найден применимый источник: официальная таблица КД МИД на 30 сентября 2026
содержит безвизовые 90 дней по соглашению 2019 года. Текст таблицы был доступен в поисковом
индексе; прямой доступ к КД МИД возвращал технические работы. Это прямо указано в условиях.
Для Кыргызстана численный срок не обещаем до отдельной проверки действующей редакции правил
регистрации 2026 года. Для Танзании не обещаем визу на границе. Бесплатная ETA Шри-Ланки —
предварительное разрешение, а не безвизовый режим. В источниках Сейшел есть календарные месяцы;
не подменяем их фиксированными днями. Действительность визового освобождения Китая ограничена
31 декабря 2027, Вьетнама — 14 марта 2028.

JSON-ответ включает словарь `sources` с URL, описаниями, датами и методами для всех ссылок.
Неизвестное не считается безвизовым. Ссылки и условия каждой страны — в `data/sources/visas.json`.

`visa_free_only` допускает внутренние поездки или официально проверенное освобождение от визы
с известным численным лимитом пребывания. Зарубежное направление с `max_stay_days=null`
исключается с причиной `unknown_visa_stay_limit`, даже если календарные месяцы указаны только
в тексте условий. Для внутренней поездки неизвестный визовый лимит не мешает подбору.
Без строгого фильтра такое зарубежное направление может попасть в результат с предупреждением:
«Численный лимит пребывания не установлен; допустимая длительность поездки не подтверждена.»

Без `departure_date` срок правила проверяется на дату среза; с датой — на весь срок поездки,
включая выезд. Месяц должен совпадать с датой. Электронная виза и виза по прибытии не считаются
безвизовым въездом. Длина поездки сравнивается с лимитом пребывания; предыдущие поездки и остаток
дней в скользящем окне не вычисляются. Это проверка сохранённого среза, а не текущая проверка
допуска в страну. При покупке правила и документы нужно проверить заново.

## Фильтрация и скоринг

Жёсткие условия: все запрошенные теги, минимальная вода, максимум осадков, максимум оценочного
времени полёта, визовый фильтр и бюджет. Если нужное значение неизвестно, соответствующий
жёсткий фильтр не проходит. `excluded` перечисляет причины, а `matched_count` учитывает все
подходящие направления до ограничения `limit`.

Балл: +10 за каждый запрошенный тег, +2 за средний воздух 20–30 °C, +2 за воду ≥24 °C,
+1 за осадки ≤80 мм/месяц. При равенстве — стабильная сортировка по ID. Каждый компонент
объясняется в `reasons`. Это простой прозрачный подбор направлений, не ранжирование готовых поездок R2.

Риски — явные эвристики климатических норм: осадки ≥150 мм/месяц, средний воздух ≥35 °C или ≤0 °C.
Они не являются прогнозами урагана, индивидуальной оценкой безопасности или текущими предупреждениями.

Если позднее появятся цены со статусом `verified`, оценка для бюджета — перелёт туда-обратно на
человека × число путешественников плюс номер/ночь × ночи × `ceil(путешественники / 2)`.
Это предварительная оценка; багаж, трансферы, виза и доплаты в неё не входят. Единицы и размещение
нужно окончательно согласовать с D2/D3/R2 на O1 перед подключением реальных котировок.

## Пересборка и проверки

```bash
make destinations-data  # собрать итоговый YAML из сохранённых источников, без сети
make destinations-check # проверить актуальность YAML и только D5-тесты, без сети
uv run --project backend --locked --offline python scripts/build_demo_hotels.py --check
uv run --project backend --locked --offline python scripts/build_demo_transport.py --check
uv run --project backend --locked --offline python scripts/build_destination_names.py --check
```

Три последние команды только сверяют производные демо-данные и подписи с
генераторами. Необязательная полная матрица данных и планировщика:
`make expanded-demo-check` — 1782 сценария, ориентировочно 100 секунд.
Она не проверяет чат, браузер, оплату или качество языковой модели.

Обновление климатических источников требует сети, NASA/NOAA и отдельного окружения h5py:

```bash
UV_CACHE_DIR=/tmp/na-maldivy-uv-cache uv run scripts/fetch_destination_climate.py
make destinations-data
```

PEP 723-зависимости h5py/PyYAML устанавливаются только для скрипта обновления. В рабочем приложении
HDF5/numpy не нужны. Полный NOAA-файл (около 46 МБ) кэшируется вне git; в репозитории хранится
извлечение для выбранных точек и SHA256 исходника. Перепроверка виз проводится вручную по
`data/sources/visas.json`; при изменении даты среза нужно сохранить актуальные источники и решения.

Стандартный Docker Compose собирает `backend/Dockerfile.demo` из корня проекта
и включает подготовленные данные в `/data` образа. Переменная `DATA_DIR=/data`
задана явно; ручное монтирование каталога не требуется.
При запуске из checkout по умолчанию
используется корневой `data/destinations.yaml`. Подбор можно вызвать внутри запущенного контейнера:

```bash
docker compose exec agent python -m app.destination_cli --month 11 --tag beach --min-water 24
```

## Адаптер D1 после review

`DestinationTool` принимает `DestinationQuery` и возвращает `list[Destination]`.
MOW/SVO/DME/VKO используют московскую оценку, LED — петербургскую; прочие точки
отправления явно отклоняются. Каталог выбирается через `Settings.data_dir` / `DATA_DIR`.
Неизвестные воздух/вода, длительность, визовый режим и цена в общем контракте допускают `null`.
Это расширение D1 необходимо для фактического справочника: отсутствие цены нельзя заменять нулём,
отсутствие визовой проверки — безвизовым въездом. Жёсткие фильтры исключают неизвестные значения.
`is_synthetic=true` отмечает расчётную длительность и оценку стоимости; источники фактов не менялись.
Фабрика общего реестра D2/D3/D5/S4 включает расширенные каталоги только при
`FLIGHTS_MODE=demo`; перечень поддержанных целей берётся из реально загруженных
данных, а не обещается по одному наличию карточки в справочнике.
