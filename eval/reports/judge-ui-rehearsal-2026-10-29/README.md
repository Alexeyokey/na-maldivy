# Репетиция сайта и исправления перед проверкой жюри

Дата: **29.10.2026, Москва**. Проверяемый код: `de83c11da512a929381a8a2f9af0a64349db8bf8`.
Документы и этот отчёт добавлены отдельным последующим commit. Старые отчёты не
переписаны и не считаются проверкой нового кода.

## Что проверено

- **1622 теста**: 1408 backend, 203 frontend, 11 proxy; Ruff и проверка формата проходят.
- Отдельная чистая рабочая копия отслеживаемых файлов, без `.env`, ключей, локальных
  зависимостей и личных заказов: Docker build/up, три направления, D7/D8,
  подтверждение корзины, отказ/успех/повтор оплаты, приватные документы и restart.
  Это повторная сборка с кэшем, а не новый замер первой установки.
- Браузер: desktop 1280 CSS px, локальные responsive iframe 320/375/390 × 640.
  В [матрице 49 сценариев](../../../docs/judge-ui-rehearsal.md) **36 passed,
  12 partial, 1 not_run**. Частичное выполнение не выдаётся за полный зачёт.
- Внешняя модель не нужна локальному стандартному запуску. Её качество не
  подтверждается тестами `fake`.

Контролируемая браузерная репетиция F01/F03/F04 выполнена отдельно: proxy
получал настоящий ответ из изолированного backend, отдавал события по первый
`delta`, удерживал соединение 8 секунд и закрывал его без `done`. Повтор отдавал
полный ответ. Проверены обрыв без перезагрузки, reload с непустым черновиком и
остановка/новый маршрут до позднего закрытия прежнего потока. Один запрос
сохраняется одним сообщением; старый поток не меняет новую поездку. Это проверка
потери транспортного результата уже выполненного запроса, а не отмены внешней
модели посередине генерации.

## Развёрнутый сайт

На `https://na-maldivy.eu.cc` обновлены agent/web из проверенного commit. HTTPS
проверен с обычной валидацией сертификата; без пароля возвращается 401. Пять
файлов интерфейса совпали с исходниками по SHA256. Существующие авторизация,
том состояния и настройки быстрой модели сохранены.

До обновления сделаны приватные согласованные SQLite-backup двух баз. После:
**8/8 прежних заказов, 16/16 документов и прежние маркеры запросов сохранены**,
хэши не изменились. В отчёте нет ID доступа, персональных данных или секретов.

Один настоящий поиск AYT: два варианта, оба авиационных плеча из снимка, известная
часть первого варианта **83 234 ₽**. Ответ — **16,515 с**; повтор того же запроса —
**0,643 с**, состояние идентично, дополнительных вызовов модели нет. Это один
контрольный поиск, а не оценка средней скорости или всей разговорной матрицы.
Реальная оплата/бронь не выполнялась.

На VPS старый Docker не поддерживает named build contexts. Private agent собран
эквивалентным контекстом из `backend/app` и того же проверенного бинарника,
без папки авторизации. Изменён только способ COPY бинарника; стандартный
публичный Docker-пакет проверен отдельно.
