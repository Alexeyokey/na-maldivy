Во временной internal-сети на этом macOS Docker опубликованный host-порт
также отключился. Этот отдельный HTTP-прогон выполнялся **внутри** сети.
После него стандартная сеть была восстановлена, и браузер проверял обычный
`localhost:8080`. Стандартный Compose сам по себе не запрещает внешний трафик.

Сборка заняла 6,684 с, готовность после `up --build` — ещё 8,160 с
на Apple M3 / 16 GiB, Docker 29.8.2 / Compose 5.5.1. Базовые слои образов
уже были на машине; шаги сборки выполнялись без build cache, Python-пакеты
скачивались заново. Это **не** измерение полностью пустого Docker Engine
или гарантия такого времени на другой сети.

Оба runtime используют `linux/amd64`, UID/GID `1000:1000`, health — healthy.
Опубликован только порт 8080. Проверено отсутствие ключей поставщиков и
backend dev-модулей; реальные значения окружения в отчёты не включены.

## Границы и оставшиеся действия

- Качество внешней LLM и настоящий LLM-прогон D7 этим пакетом не подтверждены.
  Локальный запуск использует правила, шаблоны и синтетические профили.
- Aviasales — исторические снимки, а не текущие предложения. Коммерческие
  условия, поезда и недостающие рейсы расчётные/синтетические. Оплата тестовая.
- Полная D9-приёмка не объявлена успешной: бюджетный `u2-03` остаётся
  [отдельно разобранным ограничением](../u2-budget-feasibility.md).
- Общедоступного видео пока нет. Требуются запись, публичная ссылка в README
  и проверка воспроизведения без аккаунта.
- Код ещё должен попасть в `main`: эта ветка продолжает PR #67.
  Перед сдачей нужно повторить проверку основной ветки.
- Тег `submission` **не создавался** по прямому указанию владельца.

В JSON нет session/order capabilities, имён путешественников или ключей.
Приватные context-файлы оставались в одноразовом Docker-томе и не включены
в этот каталог. [SHA256 файлов доказательств](manifest.json).
