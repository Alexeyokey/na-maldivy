# О!дин запрос · интерфейс команды «На Мальдивы»

Buildless ES modules: HTML, CSS, JavaScript. Node.js 22+, без npm install. Из корня: `make web`, `make web-demo`, `make web-test`. Сервер слушает localhost:5173; `PORT`, `HOST`, `AGENT_URL`, `CHAT_MODE` можно задать через окружение.

## Где что находится

- `dist/app.js` — UI, история, доступность, отмена и повтор, локальный демонстрационный сценарий.
- `dist/polish.css` — эффекты появления новых сообщений и карточек, фокус, touch-targets, reduced motion.
- `dist/api.js` — отдельный клиент фактического SSE-контракта репозитория. Не знает про макет и каталог.
- `dist/trip-canvas.js` — проверка и проекция серверного брифа, источников, версии и сессии из ветки `orchestrator`.
- `dist/engine.js` — только автономная демонстрация, не контракт серверного TripState.
- `server.mjs` — статические файлы и потоковый same-origin прокси к двум существующим методам агента.
- `dist/config.js` — статическая конфигурация автономного демо. Локальный сервер генерирует её в памяти с режимом API; секретов в браузере нет.

Первый `POST /api/chat` получает `{message}` с длиной 1–4000. Если сервер прислал `session_id` в `done`, следующие сообщения передают этот ID в том же контракте, поддержанном веткой `orchestrator`. Текст добавляется как текст, не HTML. Клиент не выдумывает history, state_patch, HTTP-методы покупки или данные поиска. Ошибки API не подменяются демонстрационными рекомендациями. При новой поездке активный запрос отменяется; старый ответ не попадает в новую беседу.

В режиме агента панель читает только событие `brief: {brief, sources, needs}` и метаданные `done: {session_id, version, stage}` из существующего `backend/app/agent/core.py` ветки `orchestrator`. Поля не извлекаются из текста ответа и не подставляются из демонстрационного каталога. Пустой холст не показывает панель. Непустой открывает её на компьютере и добавляет кнопку «Поездка» на телефоне. Пометки `explicit / inferred / default` видны как «Из чата / Выведено / Допущение». События одного хода показываются предварительно и сохраняются только после `done`; ошибка, отмена и обрыв оставляют прежний подтверждённый холст.

Бюджет, кнопки +2,5/+5/+10%, дата, ночи, взрослые и направление отправляют агенту обычное сообщение с текущим `session_id`. Значения подтверждаются новым брифом сервера, несохранённый черновик чата остаётся на месте. Если агент не принял правку, панель возвращает значение из холста и показывает уведомление. При перезагрузке `GET /api/session/{session_id}` восстанавливает серверный снимок; 404 очищает завершённую сессию. Прокси разрешает только чтение снимка, без удаления сессий.

Старый `main`, передающий только `delta/done/error` без брифа, остаётся совместимым текстовым чатом. Появление панели в режиме агента требует сервера с холстом из `orchestrator`; интерфейс не имитирует отсутствующие данные. Статический Site сохраняет автономный режим, поскольку сервер Python отдельно не развёрнут.

Цены контрактов backend `price_rub` уже относятся ко всей группе и указанному объёму услуги. Их нельзя напрямую присваивать демонстрационной цене номера за ночь. Карточки вариантов и покупка требуют отдельного адаптера O1/R1; эта интеграция их не подменяет.

## Поведение UI

Анимация запускается только для новых ID сообщений. Старые сообщения инициализируются без анимации. При изменении параметров сохраняются черновик, selection, фокус, положение чата и каруселей. При чтении истории новый ответ не утягивает вниз; появляется кнопка перехода. Cmd/Ctrl+K ставит фокус в ввод. Enter отправляет, Shift+Enter переносит строку. Все эффекты отключаются при `prefers-reduced-motion`.

Пустой старт и скрытая до первого критерия панель сохранены. В демо предложения, сравнение и улучшения доступны только после направления, бюджета на всю поездку, дат заезда/выезда и числа гостей. Параметры и тестовые заказы хранятся локально. Удаление памяти доступно в профиле.

## Проверки

`npm test` проверяет ядро демо, обязательные критерии, расчёт общего бюджета и транспорт SSE (разрыв UTF-8/CRLF, ошибки после частичного текста, отмена, валидация, преждевременный EOF).

В демо `hotelTotal` складывает тариф номера за все ночи (с завтраком и питомцем, если выбраны) и разовые 35% базовой ночи за ранний заезд. `planTotal` прибавляет билеты туда и обратно за всех гостей и выбранный трансфер в обе стороны. `checkBudget` проверяет полную сумму: равенство бюджету допускается, превышение даже на рубль исключается. Поиск, выбор отеля и подтверждение оформления повторно применяют проверку. Карточки и план показывают всю стоимость и остаток. Изменение транспорта и трансфера снимает выбранный отель, если он перестал подходить. `tests/budget.test.mjs` сравнивает результат с независимым расчётом для всех городов и тарифов, разных дат, гостей, транспорта и дополнительных услуг. Серверные `price_rub` по-прежнему не преобразуются в демонстрационные ночные тарифы.

`npm run test:integration` поднимает временные локальные HTTP-серверы и проверяет фактический прокси без внешних сервисов и ключей.

Фото: локальные иллюстративные копии Unsplash. Шрифт Manrope загружается с Google Fonts; при недоступности используется системный. Все JS/CSS и фото доступны локально.

## Отмена демо-поездки

В «Моих поездках» доступна отмена всего заказа с отдельным подтверждением. Статус и дата отмены сохраняются локально; отменённая поездка остаётся в истории. Изменение дат, ранний заезд, трансфер и создание напоминания для неё недоступны. Повторная отмена не создаёт новое событие. Старые заказы без поля status продолжают работать. Возврат лишь имитируется, поскольку реальной оплаты не было; календарное событие, ранее импортированное пользователем, автоматически не удаляется. Серверные контракты не изменены.
