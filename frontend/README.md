# О!дин запрос · интерфейс команды «На Мальдивы»

Buildless ES modules: HTML, CSS, JavaScript. Node.js 22+, без npm install. Из корня: `make web`, `make web-demo`, `make web-test`. Сервер слушает localhost:5173; `PORT`, `HOST`, `AGENT_URL`, `CHAT_MODE` можно задать через окружение.

## Где что находится

- `dist/app.js` — UI, история, доступность, отмена и повтор, локальный демонстрационный сценарий.
- `dist/polish.css` — эффекты появления новых сообщений и карточек, фокус, touch-targets, reduced motion.
- `dist/api.js` — отдельный клиент фактического SSE-контракта репозитория. Не знает про макет и каталог.
- `dist/engine.js` — только автономная демонстрация, не контракт серверного TripState.
- `server.mjs` — статические файлы и потоковый same-origin прокси к двум существующим методам агента.
- `dist/config.js` — статическая конфигурация автономного демо. Локальный сервер генерирует её в памяти с режимом API; секретов в браузере нет.

`POST /api/chat` получает `{message, session_id?}`. `session_id` приходит в событии `done`, хранится вместе с историей в localStorage и отправляется со следующими сообщениями: так агент помнит разговор. Кнопка «Новая поездка» начинает новый разговор. Текст добавляется как текст, не HTML. Ошибки API не подменяются демонстрационными рекомендациями. При новой поездке активный запрос отменяется; старый ответ не попадает в новую беседу.

Кроме текста (`delta`) клиент показывает события агента (`api.js` → `onEvent`, отрисовка — `apiExtras` в `app.js`):

- `question` — кнопки быстрых ответов под последним ответом;
- `options` — карточки направлений, собранных поездок и поездов: «почему подходит», «чем жертвуем», «риски» и кнопка «Выбрать», которая отправляет «давай N» / «беру N»;
- `booking` — отметка о демо-брони.

Остальные события пропускаются. Правила отображения из [docs/frontend-handoff.md](../docs/frontend-handoff.md) соблюдены: `total_rub: null` не показывается числом, известная часть суммы не называется полной ценой, при `can_confirm=false` выводится предупреждение. Оформление через `/api/checkout/*` в интерфейсе пока не сделано: прокси пропускает только `/api/chat` и `/health`.

## Поведение UI

Анимация запускается только для новых ID сообщений. Старые сообщения инициализируются без анимации. При изменении параметров сохраняются черновик, selection, фокус, положение чата и каруселей. При чтении истории новый ответ не утягивает вниз; появляется кнопка перехода. Cmd/Ctrl+K ставит фокус в ввод. Enter отправляет, Shift+Enter переносит строку. Все эффекты отключаются при `prefers-reduced-motion`.

Пустой старт и скрытая до первого критерия панель сохранены. В демо предложения, сравнение и улучшения доступны только после направления, бюджета на всю поездку, дат заезда/выезда и числа гостей. Параметры и тестовые заказы хранятся локально. Удаление памяти доступно в профиле.

## Проверки

`npm test` проверяет ядро демо, обязательные критерии и транспорт SSE (разрыв UTF-8/CRLF, ошибки после частичного текста, отмена, валидация, преждевременный EOF).

`npm run test:integration` поднимает временные локальные HTTP-серверы и проверяет фактический прокси без внешних сервисов и ключей.

Фото: локальные иллюстративные копии Unsplash. Шрифт Manrope загружается с Google Fonts; при недоступности используется системный. Все JS/CSS и фото доступны локально.

## Отмена демо-поездки

В «Моих поездках» доступна отмена всего заказа с отдельным подтверждением. Статус и дата отмены сохраняются локально; отменённая поездка остаётся в истории. Изменение дат, ранний заезд, трансфер и создание напоминания для неё недоступны. Повторная отмена не создаёт новое событие. Старые заказы без поля status продолжают работать. Возврат лишь имитируется, поскольку реальной оплаты не было; календарное событие, ранее импортированное пользователем, автоматически не удаляется. Серверные контракты не изменены.
