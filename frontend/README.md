# О!дин запрос · интерфейс команды «На Мальдивы»

HTML/CSS/ES modules без сборщика и npm install; Node.js 22+. npm run dev запускает localhost:5173. Настройки: AGENT_URL (по умолчанию http://127.0.0.1:8000), CHAT_MODE=api (по умолчанию), PORT, HOST. Docker Compose задаёт AGENT_URL=http://agent:8000.

## Настоящий API-путь

В режиме api бриф, варианты, котировки и оформление приходят с backend. Локальный engine.js здесь не вызывается. Ошибка API остаётся явной ошибкой: локальные предложения и успешная оплата вместо серверного ответа не создаются. Серверный CHAT_MODE имеет приоритет над старой настройкой браузера.

1. Введите запрос или выберите Анталью / Дубай / Мальдивы. session_id из done передаётся в следующих сообщениях. Карточки строятся из options; панель — из brief и актуального снимка сессии. Вопросы имеют серверные быстрые ответы. D7/D8 показывают серверные объяснения и сравнения.
2. Выберите карточку, проверьте состав и нажмите «Подтверждаю состав». Это сообщения в настоящий чат, который создаёт неоплаченную серверную корзину. Клиент не присылает собственную цену.
3. Форма содержит вымышленные имена и тестовые даты рождения. Два отдельных согласия — с имитацией оплаты и с неоценёнными расходами — изначально не отмечены. Карта не запрашивается.
4. «Проверить отказ оплаты» отправляет declined: заказ не создаётся. «Оплатить в демо» отправляет approved, после чего успех показывается только при серверном paid_demo и is_simulated=true. Идемпотентный ключ сохраняется при неоднозначной сетевой ошибке; данные путешественников повторно не отправляются без необходимости.
5. Ваучер и .ics скачиваются через приватный запрос с X-Session-ID и Blob. Идентификаторы доступа и технические номера объектов в UI не выводятся. «Мои поездки» открывает серверные демо-заказы этой вкладки.

Источник указан для каждого плеча: сохранённая котировка Aviasales либо явно подписанный ДЕМО-МОК. Мок не получает фиктивный price_source. Показанная сумма относится к обоим рейсам, багажу, отелю и трансферу в отель; обратный трансфер, визы и прочие обязательные расходы помечены как неизвестные. Наличие мест и цена покупки не подтверждены. Деньги не списываются, билеты не выписываются, отели и трансферы не бронируются.

## Файлы и границы

- dist/api-app.js — API-renderer, карточки, модальные окна, форма и скачивание; использует прежние CSS-классы и локальные фотографии.
- dist/api-model.js — состояние диалога, SSE, серверные корзины/оплата и приватные ссылки на заказы; не импортирует engine.
- dist/api.js — потоковый клиент SSE и checkout. Все события сохраняются, UTF-8/CRLF обрабатываются потоково.
- dist/app.js, dist/engine.js, dist/bookings.js — отдельный старый локальный прототип, доступный только при явном CHAT_MODE=demo или статической конфигурации. Его предложения и отмены не объявляются серверными.
- server.mjs — статические файлы и узкий same-origin proxy: чат, здоровье, сессия, корзина, заказы и документы. Другие маршруты/методы запрещены, тело ограничено 64 КБ, заголовки передаются по allowlist. Окружение в браузер не отправляется.

Приватные идентификаторы и публичные DTO текущей сессии сохраняются в sessionStorage вкладки; имена и даты рождения туда не записываются. Новая поездка сбрасывает текущую сессию, корзину и оплату, сохраняя доступ к прежним демо-документам. После перезапуска backend незавершённый поиск требуется начать заново; существующие заказы читаются из SQLite.

Фотографии локальные, иллюстративные и не выдают себя за фотографии выбранных отелей. Google Fonts не запрашивается: используются системные шрифты. Стили, фото и JS доступны офлайн. Проверки полного пути в браузере выполняются отдельно от автоматических тестов: сами тесты не доказывают весь D9.

## Проверки

npm run check — синтаксис модулей. npm test — локальный прототип, SSE, server-owned состояние, сессия, отсутствие подмены данных, согласия, отказ/успех, идемпотентность и документы. npm run test:integration — настоящие временные HTTP-серверы, allowlist proxy, потоковый ответ, приватные заголовки и скачивание без внешних сервисов и ключей.

## Совместимость с изменениями web2 в main

Из `main` сохранены `dist/trip-canvas.js`, его тесты и совместимый `fetchSessionCanvas`: модуль проверяет серверные поля, источники, сессию и версию, не выводя их из текста ответа. Код прежнего canvas-интерфейса сохранён в `app.js`. Основной API-режим использует `api-app.js` и `api-model.js`, которые также обслуживают серверные карточки, оформление, документы и восстановление потока; локальный прототип не подменяет этот путь.

В локальном прототипе сохранены изменения web2: карточки показывают полную стоимость поездки, сравнение с общим бюджетом и остаток; изменение транспорта или трансфера повторно проверяет выбранный отель. `hotelTotal` включает разовую доплату за ранний заезд, `planTotal` добавляет дорогу и трансфер. Поиск и оформление исключают превышение бюджета даже на рубль. Серверные групповые цены не превращаются в локальный ночной тариф.
