# База трансферов аэропорт → отель

Задача S4 ([#16](https://github.com/ostrovok-hackathon-2026/na-maldivy/issues/16)). Три демо-направления: Анталья (AYT), Дубай (DXB), Мальдивы (MLE), по 20 реальных отелей на каждое.

В ветке У2 поиск D3 использует тот же `../hotels/osm_hotels.json`: все 60 ID,
названия и координаты совпадают. При унификации сохранены 136 вариантов S4
и 40 OSRM-маршрутов. Команда `scripts/fetch_hotels.py` из корня репозитория
только проецирует этот снимок в D3 без сети; самостоятельного второго списка нет.

| Файл | Что внутри | Откуда |
|---|---|---|
| `../hotels/osm_hotels.json` | отели: `hotel_id`, название, район, координаты, звёзды | OpenStreetMap |
| `airports.json` | аэропорты: код IATA, координаты, часовой пояс | OpenStreetMap |
| `routes_osrm.json` | время и расстояние по дорогам от аэропорта до отеля (Анталья, Дубай) | OSRM |
| `transfers.json` | база: варианты трансфера для каждого отеля с ценами, расписанием и метками | модель из `backend/scripts/build_transfers.py` |
| `cases.json` | эталонные случаи: запрос → правильный ответ, по ним тестируется `quote_transfers` | размечено вручную |

## Как пересобрать

```bash
cd backend
uv run python scripts/build_transfers.py fetch   # нужна сеть, обновляет отели, аэропорты и дороги
uv run python scripts/build_transfers.py build   # без сети, пересчитывает transfers.json
uv run pytest tests/test_transfers.py
```

`fetch` выбирает отели детерминированно, но данные OSM со временем меняются. Поэтому его результат закоммичен, а `build` всегда даёт тот же `transfers.json`. После `fetch` проверьте `cases.json`: эталоны ссылаются на конкретные `hotel_id`.

После изменения общего снимка пересоберите данные D3/D7 и проверьте связку:

```bash
cd ..  # вернуться из backend/ в корень репозитория
backend/.venv/bin/python scripts/fetch_hotels.py
backend/.venv/bin/python scripts/build_hotel_profiles.py --generate-demo-data
backend/.venv/bin/python scripts/fetch_hotels.py --check
backend/.venv/bin/python scripts/build_hotel_profiles.py --check
make u2-compat-check
```

`--check` у проектора D3 не пишет файлы. Его `sources.json` содержит SHA256
нормализованного S4-снимка; отсутствующие raw-метаданные OSM не восстанавливаются
по догадке. Старые raw-ответы D3 и `legacy_sources.json` сохранены как архив.
Подробнее — [документация отелей](../../docs/hotels.md).

## Что настоящее, а что синтетика

- **Настоящее:** сохранённые записи OSM об отелях, их координатах и районах,
  аэропортах; расчётные время и расстояние по дорогам для Антальи и Дубая
  (OSRM, без живых пробок). Это данные карты и модели маршрутизации,
  а не подтверждённые поставщиком условия размещения или перевозки.
- **Синтетика:** цены, расписания, правила про детей, животных и багаж, время на воде и в воздухе на Мальдивах (по расстоянию). Параметры — `TARIFFS` в `backend/scripts/build_transfers.py`.

## Поля варианта трансфера

| Поле | Значение |
|---|---|
| `id` | `<hotel_id>:<аэропорт>:<вид>` |
| `mode` | `taxi`, `private_minivan`, `shuttle`, `metro`, `speedboat`, `seaplane`, `flight_speedboat` |
| `duration_min`, `distance_km` | время в пути с ожиданием и расстояние |
| `pricing.type` | `per_vehicle` — цена за машину на `capacity` мест; `per_person` — за взрослого, `child_price_rub` за ребёнка 2–11 лет, до 2 лет бесплатно |
| `pricing.night_multiplier`, `night_hours` | ночная наценка и когда она действует |
| `hours` | местное время работы `{from, to}`; `null` — круглосуточно; `to` меньше `from` — через полночь |
| `luggage_limit` | ограничение багажа текстом или `null` |
| `child_seat`, `pets` | `true`, `false` или `null` — неизвестно. Неизвестно ≠ нет |
| `prebook_hours` | за сколько часов бронировать, `0` — не нужно |
| `source` | `osrm` — время по реальным дорогам, `synthetic` — по модели |

## Виды трансфера

| Где | Виды |
|---|---|
| Анталья | такси (24/7, ночная наценка ×1,3), минивэн по предзаказу (7 мест, кресла, животные), шаттл 06:00–23:00 |
| Дубай | такси (24/7), минивэн по предзаказу, метро 05:00–00:00 в районах с метро (не на Пальме) |
| Мальдивы, острова Мале, Хулхуле и Хулхумале | такси: острова связаны мостом |
| Мальдивы, остальные острова до 60 км | катер: у части курортов только 06:00–22:00, у остальных ночью ×1,5 |
| Мальдивы, 60–220 км | гидросамолёт только днём 06:00–15:30, 20 кг багажа, бронь за 72 часа |
| Мальдивы, дальше 220 км | местный рейс и катер 06:00–21:00, бронь за 48 часов |

## Метки варианта (`options[].labels`)

| Метка | Когда |
|---|---|
| `long_transfer` | дольше 90 минут |
| `no_night_service` | есть расписание, не круглосуточно |
| `daylight_only` | гидросамолёт |
| `luggage_limit` | есть ограничение багажа |
| `prebook_required` | бронировать за 24 часа и раньше |
| `no_child_seat` | детского кресла точно нет |
| `pets_forbidden` | животных точно не берут |
| `small_capacity` | машина на 4 места и меньше |
| `night_surcharge` | есть ночная наценка |
| `multi_leg` | пересадка: местный рейс и катер |

## Метки отеля (`labels`)

| Метка | Когда | Чем опасно |
|---|---|---|
| `only_scheduled_transfer` | у отеля нет круглосуточного трансфера | ночной прилёт: до отеля не добраться до утра |
| `far_from_airport` | самый быстрый трансфер дольше 90 минут | долгая дорога после перелёта, особенно с детьми |

## Проблемы в ответе `quote_transfers`

Метки описывают базу, а проблемы (`issues`) — конкретный запрос: время, состав группы, животные.

| Проблема | Когда |
|---|---|
| `unavailable_at_pickup` | в запрошенное время не ходит, `depart_at` — ближайший рейс |
| `extra_vehicle` | группа не помещается в одну машину |
| `night_surcharge` | применилась ночная наценка |
| `pets_forbidden`, `pets_unknown` | с животным, а перевозчик не берёт или неизвестно |
| `child_seat_missing`, `child_seat_unknown` | в машине ребёнок младше 12, а кресла нет или неизвестно |
| `long_transfer`, `prebook_required`, `luggage_limit` | как у меток |

## Эталонные случаи `cases.json`

Каждый случай — запрос и ожидаемый ответ, ожидания посчитаны вручную по полям базы, а не кодом:

```json
{
  "id": "mle-seaplane-night",
  "why": "Прилёт ночью, до курорта только гидросамолёт",
  "hotel_id": "osm:way/123",
  "airport": "MLE",
  "pickup_at": "2026-11-18T23:40:00+05:00",
  "travelers": {"adults": 2},
  "expect": {
    "hotel_labels": ["only_scheduled_transfer"],
    "modes": ["seaplane"],
    "first": {"mode": "seaplane", "available": false, "depart_at": "2026-11-19T06:00:00+05:00"},
    "issues": {"seaplane": ["unavailable_at_pickup", "prebook_required", "luggage_limit"]},
    "price_rub": {"seaplane": 99000}
  }
}
```

`modes` — какие виды вернулись (без учёта порядка), `first` — поля первого варианта в выдаче, `issues` и `price_rub` — точные значения для указанных видов.
