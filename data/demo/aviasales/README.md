# Публичный снимок Aviasales для офлайн-демо

Реальные ответы Data API получены 28.10.2026 через D4 в режиме `record`.
Сюда перенесены 17 обезличенных записей: SVO → AYT на 15–21.11.2026,
AYT → SVO на 22–29.11.2026, SVO → DXB/MLE на 18.11.2026.
Ключи и авторизационные заголовки исключены.
`manifest.json` фиксирует происхождение, время записи и SHA256 каждого файла.

Основной сценарий: Москва → Анталья, 18–25 ноября 2026, двое взрослых.
Котировки за одно место: 11 251 ₽ туда, 14 147 ₽ обратно. Запись запроса DXB
содержит фактический DWC и намеренно не даёт подходящего рейса при поиске DXB.
Обратного рейса Мальдив в этом снимке нет. Соседние даты Антальи позволяют
сравнить ±3 дня; за пределами снимка отсутствие котировки не подменяется
синтетикой и не позволяет обещать экономию.

Это наблюдения из поискового кэша провайдера, не наличие мест и не цена покупки.
Групповая цена и багаж рассчитываются моделью D2; отель и трансфер — демонстрационные.
Время `recorded_at` означает нашу запись ответа, не последнюю проверку тарифа поставщиком.

Проверка без ключа и сети: `make demo-cache-check`.
Для локального backend: `FLIGHTS_MODE=aviasales`, `TOOLS_MODE=real`,
`CACHE_MODE=replay`, `AVIASALES_CACHE_DIR=<путь к этой директории>`, `LLM_PROVIDER=fake`.
Для контейнера есть `docker-compose.demo.yml`. При record используйте отдельный
runtime-кэш, чтобы не перезаписывать этот зафиксированный снимок.
