# Публичный снимок Aviasales для офлайн-демо

47 настоящих очищенных ответов Data API получены 28.10.2026 через D4 в `record`.
`manifest.json` фиксирует время записи и SHA256. Моки не записываются в эту
директорию и не выдаются за ответы провайдера. Ключи и авторизационные заголовки исключены.

| Запросы | Даты ноября 2026 | Что реально получено |
|---|---|---|
| SVO → AYT | 15–21 | Подходящие котировки SVO → AYT |
| AYT → SVO | 22–29 | Подходящие котировки AYT → SVO |
| SVO → DXB | 15–21 | Провайдер вернул DWC; эти записи не подходят для рейса в DXB |
| DXB → SVO | 22–30 | Подходящие рейсы 23, 25, 26, 29, 30 ноября; остальные ответы отфильтровываются |
| SVO → MLE | 15–21 | Подходящие котировки туда |
| MLE → SVO | 22–30 | Подходящие котировки обратно |

Основной сценарий Антальи: 18–25 ноября, двое взрослых. За одно место:
11 251 ₽ туда, 14 147 ₽ обратно. Мальдивы теперь имеют реальные снимки обоих
плеч. Для Дубая в явном `FLIGHTS_MODE=demo` недостающее плечо дополняется
детерминированным мок-рейсом DXB; DWC не переименовывается в DXB.

Строгий `FLIGHTS_MODE=aviasales` продолжает возвращать ошибку/пустую выдачу при
отсутствии подходящего ответа. Только отдельный режим `demo` использует подписанные
моки при отсутствии данных. Ошибки HTTP/формата и слишком дорогие существующие
котировки не скрываются более дешёвыми моками.

Это поисковые наблюдения, не наличие мест и не цена покупки. Цена группы и багаж
расчётные, отели и трансферы демонстрационные. `recorded_at` означает время нашей
записи ответа, не последнюю проверку поставщиком. Сравнение с моками в D8 —
демонстрационная оценка экономии, а не подтверждение настоящего тарифа.

Проверка без ключа и сети: `make demo-cache-check`.
Локально: `TOOLS_MODE=real`, `FLIGHTS_MODE=demo`, `CACHE_MODE=replay`,
`AVIASALES_CACHE_DIR=<путь к этой директории>`, `LLM_PROVIDER=fake`.
`make demo-up` использует этот режим. При `record` выбирайте отдельный runtime-кэш.
